# Smart Census Management System

A Python-based web application designed to manage census records with blockchain-based verification.

## Features

- User registration and login
- Census record management
- Add, view, edit, and manage records
- SQLite database integration
- Blockchain-based record verification
- Blockchain transaction history
- Flask-powered web interface

## Tech Stack

- **Language:** Python
- **Backend:** Flask
- **Frontend:** HTML, CSS, Jinja2
- **Database:** SQLite
- **Blockchain:** Solidity, Web3.py

## Getting Started

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies required by the project.
4. Configure the database and blockchain environment as needed.
5. Run the Flask application using the project's configured entry point.

## Purpose

This project demonstrates census record management using Python and database operations, with blockchain technology intended to support record integrity and verification.
